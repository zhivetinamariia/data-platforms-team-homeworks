# Практическое задание 01

## Задача

Необходимо задокументировать или реализовать автоматизированное развертывание кластера HDFS, включающего в себя 3 DataNode и обязательные для функционирования кластера сервисы: NameNode, Secondary NameNode.

Перед сдачей результатов можно выполнить их проверку, убедившись, что кластер целостный:

Вариант 1: Зайти в интерфейс NameNode в Hadoop. В нем не должны быть деградировавших нод, должны присутствовать 3 работающих DataNode.

Вариант 2: В логах кластера не должно быть критических ошибок.

## Критерии оценивания

> Все приведенные оценки действительны при сдаче в срок.  
> При нарушении срока сдачи — штраф 20%.

| Баллы | Условия |
|---|---|
| **8–10** | Все необходимые шаги присутствуют, нет ошибок |
| **10** | Артефакты включают в себя инструкцию и скрипты автоматизированного выполнения |
| **9** | Артефакты включают в себя только скрипты |
| **8** | Артефакты включают в себя только инструкцию |
| **5–7** | Все необходимые шаги присутствуют, но есть небольшие ошибки |
| **7** | Есть инструкция и скрипты |
| **6** | Есть только скрипты |
| **5** | Есть только инструкция |
| **1–4** | Пропущены ключевые шаги, присутствуют ошибки, нет целостной последовательности |
| **4** | Пропущены 1 ключевой шаг, но есть инструкции и скрипты |
| **3** | Пропущены более 1-го ключевого шага, но есть инструкции и скрипты |
| **2** | Пропущен хотя бы 1 ключевой шаг и есть только скрипты |
| **1** | Пропущен хотя бы 1 ключевой шаг и есть только инструкция |
| **0** | Задание не сдано и/или не выполнено |
